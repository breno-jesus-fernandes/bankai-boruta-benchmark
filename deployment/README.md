## IAM review baseline

`iam-baseline.review.json` was generated by IAM Policy Autopilot 0.3.0 from the
actual SDK callers. It is **not an approved deployment policy**: runtime resource
names remain broad, and CloudFormation's dependent resource permissions must be
reviewed separately. It has not been uploaded or attached. Reproduce with:

```sh
DISABLE_IAM_POLICY_AUTOPILOT_TELEMETRY=true uvx iam-policy-autopilot@0.3.0 generate-policies \
  "$PWD/src/bankai_benchmark/aws_ecs.py" \
  "$PWD/src/bankai_benchmark/budget.py" \
  "$PWD/src/bankai_benchmark/orchestrator.py" \
  "$PWD/src/bankai_benchmark/ecs_entrypoint.py" \
  --region us-east-1 --account 642504869083 \
  --service-hints cloudformation ecs ecr autoscaling s3 --pretty
```

Do not attach this baseline as-is. Resolve resource names, review PassRole and
CloudFormation permissions, then approve the resulting scoped identity policy.

## Budget monitoring

A monitoring-only monthly account budget `bankai-benchmark-guard` was created
at USD20, with actual-cost alerts at USD2/10/16/20 to the user-provided address.
The existing USD5 budget was preserved. Credits and refunds are excluded from
this new budget so they do not hide gross usage. Taxes are included when billed.
The planning conversion ceiling of BRL6.5/USD and 30% margin maps USD20 to
BRL169; it is an assumption, not a currency guarantee. This monthly alert does
not replace the campaign-wide BRL160 reservation ledger and BRL40 reserve.

No compute was started. Before launch: complete dedicated access and compliance
checks, provision the zero-capacity stack, publish the CI-verified amd64 image,
register its digest, and review the final BRL20/one-hour pilot configuration.

The locked SDK dependency includes `boto3[crt]`: the CLI login credential
provider requires AWS CRT. Actual SDK access using profile `bankai` was tested
against the deployed bootstrap resources without exporting credentials.
