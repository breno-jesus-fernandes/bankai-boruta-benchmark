# Bankai Boruta reproducible benchmarks

Implementation in progress. This repository contains the benchmark suite and an
isolated upstream native-control correction. Development artifacts are for smoke
verification only; paper runs require a corrected, verified public Bankai release.

Python 3.11 or newer: `uv sync --locked`, then `make test` and `make smoke`.
See `VERIFICATION.md` for measured validation and outstanding release requirements.
